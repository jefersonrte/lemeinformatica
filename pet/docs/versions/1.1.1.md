# Leme Pet 1.1.1

Data: 2026-08-05

## Objetivo

Permitir que o dashboard de `lemesolucoesemti.com.br` reutilize a autenticacao
central sem copiar senha, banco local ou chave permanente de API.

## Fluxo de acesso

1. O dashboard redireciona para `/pet/sso-start.php` no dominio principal.
2. O usuario entra com a mesma conta do Leme Pet, caso ainda nao tenha sessao.
3. O dominio principal emite um codigo aleatorio, valido por dois minutos.
4. O backend do dashboard troca o codigo uma unica vez por um token de oito horas.
5. O token fica somente na sessao PHP do segundo dominio e autentica os relatorios.
6. Fechar o painel revoga o token no banco principal.

## Migracao

`003_v1_1_1_pet_sso_dashboard.sql` cria `pet_sso_tokens`, com hashes do codigo e
do token, prazos independentes, revogacao e ultimo uso. Valores brutos nao sao
armazenados no banco.

## Aceitacao

1. Abrir `https://lemesolucoesemti.com.br/pet/` sem sessao.
2. Confirmar o redirecionamento ao login de `lemeinformatica.com.br`.
3. Entrar e confirmar o retorno automatico ao dashboard.
4. Atualizar os graficos e confirmar resposta HTTP 200 do proxy local.
5. Fechar o painel e confirmar resposta HTTP 401 no proxy sem sessao.

O roteiro automatizado fica em `pet/tests/production-smoke.mjs` e recebe as
credenciais somente por `PET_TEST_EMAIL` e `PET_TEST_PASSWORD`.
