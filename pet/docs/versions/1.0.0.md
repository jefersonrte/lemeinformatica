## Roteiro de validacao

1. Entrar com um administrador e abrir `/pet/`.
2. Confirmar os quatro indicadores do dashboard.
3. Cadastrar um tutor com foto.
4. Cadastrar dois animais para o mesmo tutor.
5. Vincular um usuario operador como veterinario.
6. Entrar com o veterinario.
7. Criar e concluir um atendimento com diagnostico e prescricao.
8. Abrir o prontuario e conferir a linha do tempo.
9. Abrir uma internacao.
10. Registrar uma evolucao clinica.
11. Conceder alta e preencher o resumo.
12. Entrar como visualizador e confirmar que somente o dashboard aparece.
13. Tentar acessar as APIs clinicas como visualizador e confirmar HTTP 403.
14. Enviar arquivo que nao seja imagem e confirmar a rejeicao.
15. Conferir o layout em desktop e celular.

## Criterios de aceite

- um tutor possui varios animais;
- fotos aparecem nas listas e no prontuario;
- historico permanece depois da alta;
- veterinario vinculado registra informacoes clinicas;
- operador sem vinculo nao registra dados clinicos;
- visualizador nao recebe dados pessoais ou prontuario;
- toda escrita exige CSRF;
- nenhuma credencial esta versionada.
