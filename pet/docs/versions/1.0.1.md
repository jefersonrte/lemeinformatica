# Leme Pet 1.0.1

Data: 2026-07-26
Status: producao

## Objetivo

Esta versao estabiliza a publicacao na Hostinger e adiciona uma carga demonstrativa auditavel para o modulo Pet.

## Conteudo da carga

- 100 tutores demonstrativos;
- 200 animais demonstrativos, com dois animais por tutor;
- 50 atendimentos concluidos com prontuario;
- 2 internacoes ativas vinculadas a atendimentos.

Os registros usam o marcador `[DEMO_PET_V1]`. Tutores recebem CPFs tecnicos da faixa reservada pela carga e animais recebem microchips no formato `DEMO-PET-V1-0001`.

## Execucao

O provisionador aplica primeiro a migracao `001_v1_0_0_pet_core.sql` e depois executa a carga em uma transacao.

```bash
curl --request POST \
  --header "X-API-KEY: $APP_API_KEY" \
  https://lemeinformatica.com.br/pet/provision-demo.php
```

A chave deve permanecer em variavel de ambiente ou cofre de segredos. Ela nunca deve ser registrada na documentacao ou no repositorio.

## Resposta esperada

```json
{
  "ok": true,
  "versao": "1.0.1-demo.1",
  "modo": "idempotente_sem_exclusao",
  "demo": {
    "tutores": 100,
    "animais": 200,
    "atendimentos": 50,
    "internacoes": 2
  }
}
```

## Garantias

- somente requisicoes `POST` autenticadas sao aceitas;
- nenhuma tabela ou registro real e removido;
- repeticoes atualizam os cadastros demonstrativos e completam itens ausentes;
- os totais demonstrativos sao validados antes do commit;
- falhas nos dados causam rollback integral da transacao;
- a operacao e registrada em `pet_audit_log`.

## Publicacao

O workflow `Deploy Hostinger` usa FTPS com validacao de certificado, gera `includes/config.php` apenas no runner e publica na raiz absoluta do dominio. Um disparo manual faz a sincronizacao completa dos arquivos rastreados.

## Verificacoes

- Pet CI em PHP 8.2 e PHP 8.4;
- validacao JavaScript;
- bloqueio de arquivos privados no repositorio;
- health check de configuracao, sessao e banco;
- teste HTTP do login e do redirecionamento de `/pet/`.
